Модуль sentinel1_sar_parser

Парсер и вычислительный конвейер выгрузки и радиометрической обработки радарных данных Sentinel-1 SAR (Synthetic Aperture Radar) Level-1 GRD через Google Earth Engine API с экспортом в формат NetCDF-4.

2. Физические характеристики спутника и сенсора

  • Космический аппарат: Sentinel-1 (созвездие спутников 1A, 1B, 1C), программа Copernicus Европейского космического агентства (ESA).
  • Тип орбиты: Солнечно-синхронная квазиполярная орбита, высота $693\text{ км}$, наклонение $98.18^\circ$.
  • Частота и длина волны: C-диапазон, центральная несущая частота $f_0 = 5.405\text{ ГГц}$, длина волны $\lambda = 5.54657\text{ см}$ ($0.0555\text{ м}$).
  • Режим съемки: Interferometric Wide Swath (IW), ширина полосы захвата (swath width) $250\text{ км}$.
  • Угол падения луча к эллипсоиду: $\theta \in [29.1^\circ, 46.0^\circ]$.
  • Уровень шума аппаратуры (NESZ): от $-22\text{ дБ}$ до $-25\text{ дБ}$.
  • Каналы поляризации:
  • VV (Vertical transmit, Vertical receive) — ко-поляризационный канал (отражение без изменения плоскости поляризации).
  • VH (Vertical transmit, Horizontal receive) — кросс-поляризационный канал (сигнал, деполяризованный средой в ортогональную плоскость).
  • ratio — поляризационное отношение, вычисляемое как $\text{ratio} = \text{VV} - \text{VH}$ в децибелах ($10 \log_{10}(\sigma^0_{\text{VV}} / \sigma^0_{\text{VH}})$).

3. Разрешение данных

  • Пространственное разрешение сенсора IW:
  • по наклонной дальности (slant range): $20\text{ м}$;
  • по азимуту (azimuth): $22\text{ м}$.
  • Пространственное разрешение сетки продукта: $20 \times 20\text{ м}$ на пиксель (задается параметром scale=20 в API computePixels).
  • Временное разрешение:
  • Период повторяемости орбитального витка: 12 суток для одного аппарата, 6 суток для созвездия из двух аппаратов.
  • Временное окно медианного композита: 3 месяца назад от каждой даты съемки (Temporal Median).

4. Этапы конвейера обработки (Pipeline)

  1. Парсинг входного GeoJSON:

    • Извлечение координат области интереса (Polygon или Point) и временного свойства time.
    • Поддержка форматов: одиночная дата YYYY-MM-DD (автоматически расширяется до 24-часового интервала [date, date + 1 day]), массив границ [start_date, end_date], массив с шагом дискретизации [start, end, P1D].

  2. Радиометрическая коррекция рельефа (RTC, Radiometric Terrain Correction):

    • Выполняется на стороне GEE по модели Уландера (Small, 2011) с использованием цифровой модели рельефа Copernicus DEM GLO-30 (COPERNICUS/DEM/GLO30_2024_1) с шагом 30 метров.
    • Пересчет удельной эффективной площади рассеяния от площади эллипсоида к истинной площади освещенной поверхности: $\gamma^0 = \sigma^0 \frac{A_\sigma}{A_\gamma} = \sigma^0 \frac{\sin \theta}{\cos \psi}$, где $\theta$ — угол падения луча к эллипсоиду, $\psi$ — угол между вектором нормали к склону $\hat{\mathbf{n}}$ и плоскостью волнового фронта радара.

  3. Временная медианная фильтрация (Temporal Median):

    • Для каждого снимка формируется выборка всех пролетов за предшествующие 3 месяца.
    • Попиксельное вычисление медианы устраняет случайные атмосферные искажения и сглаживает спекл во времени.

  4. Выгрузка растровых массивов:

    • Экспорт через прямой шлюз ee.data.computePixels в формате NUMPY_NDARRAY с пространственным шагом 20 метров.

  5. Пространственная адаптивная фильтрация Gamma MAP:

    • Байесовский фильтр Maximum A Posteriori в локальном окне $3 \times 3$ пикселя ($w=3$) с эквивалентным числом некогерентных отсчетов $L=5.0$.
    • Однородные области с коэффициентом вариации $C_I \le C_u = 1/\sqrt{5} \approx 0.4472$ сглаживаются до локального среднего $\bar{I}$.
    • Точечные цели и резкие границы с $C_I \ge C_{\max} = \sqrt{2/5} \approx 0.6325$ сохраняются без сглаживания ($\hat{I} = I$).
    • Промежуточные текстурированные зоны ($C_u < C_I < C_{\max}$) рассчитываются через аналитическое решение квадратного уравнения с априорным гамма-распределением сигнала.

  6. Логарифмическое масштабирование в децибелы (дБ):

    • Пересчет каналов мощности: $\text{VV}_{\text{dB}} = 10 \log_{10}(\sigma^0_{\text{VV}})$, $\text{VH}_{\text{dB}} = 10 \log_{10}(\sigma^0_{\text{VH}})$.
    • Поляризационное отношение: $\text{ratio}_{\text{dB}} = \text{VV}_{\text{dB}} - \text{VH}_{\text{dB}}$.

  7. Формирование NetCDF-4:

    • Сборка многомерного массива xarray с типами float32 для радарных переменных и float64 для географических координат.

5. Скорость работы пайплайна (Бенчмарки)

Замеры выполнены на тестовом полигоне площадью $\approx 20\text{ км}^2$ ($0.05^\circ \times 0.05^\circ$, сетка $557 \times 558$ пикселей $\approx 310\,800$ ячеек растра):

Этап обработки Затраченное время Доля времени
Инициализация GEE и фильтрация каталога гранул $1.2\text{--}2.0\text{ с}$ $18\%$
Серверный расчет RTC + медиана 3 мес. + computePixels $4.5\text{--}6.5\text{ с}$ $75\%$
Пространственный фильтр Gamma MAP ($3 \times 3$ NumPy) $0.035\text{ с}$ ($35\text{ мс}$) $< 1\%$
Конвертация в децибелы и расчет ratio $0.010\text{ с}$ ($10\text{ мс}$) $< 1\%$
Сериализация и запись NetCDF-4 на диск $0.15\text{--}0.25\text{ с}$ $6\%$
Полный цикл выполнения (1 дата) $6.0\text{--}8.5\text{ с}$ $100\%$
  • Средняя пропускная способность конвейера: $\approx 35\,000\text{--}50\,000$ ячеек растра в секунду.

7. Спецификация входных и выходных данных

Входной формат (GeoJSON, RFC 7946)

Файл input_geo.json с полигоном и временным диапазоном:

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "time": ["2024-05-01", "2024-05-20"],
        "is_rectangle": true
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [
          [
            [40.10, 55.45],
            [40.20, 55.45],
            [40.20, 55.55],
            [40.10, 55.55],
            [40.10, 55.45]
          ]
        ]
      }
    }
  ]
}

Выходной формат (NetCDF-4 / Classic)

Итоговый файл output_data.nc:

  • Оси и координаты:
  • time: datetime64[ns] — метки дат пролетов спутника.
  • latitude: float64 — массив широт, строго монотонно убывающий (с севера на юг).
  • longitude: float64 — массив долгот, строго монотонно возрастающий (с запада на восток).
  • Переменные:
  • VV: float32 (time, latitude, longitude) — ко-поляризационный коэффициент рассеяния в дБ.
  • VH: float32 (time, latitude, longitude) — кросс-поляризационный коэффициент рассеяния в дБ.
  • ratio: float32 (time, latitude, longitude) — поляризационная разность $\text{VV} - \text{VH}$ в дБ.
  • Глобальные атрибуты:
  • units: "dB"
  • resolution_meters: 20
  • description: "Sentinel-1 RTC Gamma-MAP processed SAR data"
